# Navigation Audit — 2026-05-12

Pre-launch audit of every clickable navigation in the Thrive app. Static sweep of the codebase + runtime crawl on production (`thrivecareer.co.uk`).

## Verdict

**PASS (1 minor finding).** **1 broken link target found** across 50+ navigation surfaces audited:

- `/contact` — referenced from 2 pages, no `app/contact/page.tsx` exists → 404 in production.

Every other anchor, `router.push`, `router.replace`, and dynamic param route resolves to an existing page. Yesterday's three signout/redirect fixes (`/api/auth/signout` → `/signout`, `/register` → `/register/employer-free`, `/my-jobs` kebab "Find candidates" removed) are confirmed working in production.

- `<Link href="…">`
- `<a href="…">` (only `/`-prefixed paths in scope)

- `redirect(…)` / `permanentRedirect(…)`
- `useRouter().push(…)` etc.

47 unique `/…` target paths extracted, normalized (`${jobId}` → `[param]`), cross-referenced against `find app -name page.tsx`.
